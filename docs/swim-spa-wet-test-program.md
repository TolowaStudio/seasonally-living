## Dry-consult pitch (health & fitness → family fun → "a fraction of a pool")

Use this order when a customer asks about swim spas now, before wet testing exists. The site's current
swim-spas hero already leads with "a fraction of a pool's cost and footprint" — this talk track
reorders it so health/fitness lands first in conversation, per this ticket's positioning call.

1. **Health and fitness first.** A swim spa gives you a current to swim or train against year-round, plus
   hydrotherapy jets for recovery. Frame it as home exercise equipment that's also water: swim in place,
   aqua jog, resistance work, and soak afterward. This is the opening line, not an add-on.
2. **Family fun second.** Once the fitness case lands, bring up the rest of the household: play, soak,
   entertain, year-round (not just summer).
3. **"A fraction of a pool" third.** Close on cost and footprint: smaller excavation, shorter install,
   lower ongoing upkeep, and it fits yards a pool can't. This is the practical objection-handler, not the
   opener — leading with price invites a feature-for-feature pool comparison instead of the fitness case.

Dry consults run now (sizing, placement, electrical, delivery). Wet tests, if approved, run April through
September, with the waitlist opening in February.

## Wet-test program outline (draft — do not run until owner workshop decision lands)

If the owners approve wet testing, this is the shape of the program. Everything below is a draft to
revise after that decision, and the waiver needs a lawyer's pass before it touches a customer.

### Sanitizing log (between every guest)

A paper or clipboard log at the swim spa, one line per test:

| Date | Time in/out | Tester name | Sanitizer added | Initials |
| --- | --- | --- | --- | --- |
| | | | | |

- Between guests: skim debris, add/verify sanitizer per the swim spa's manual dosing, note it on the
  log, wipe down steps/rails and any shared equipment (noodles, belts).
- No back-to-back tests without a logged sanitizing step in between, even if the next guest is family.

### Liability waiver (draft outline only — lawyer review required before any use)

Starting point for counsel, not a usable waiver:

- Tester name, date, emergency contact.
- Assumption-of-risk language for water-based exercise/swimming (slipping, drowning risk for
  non-swimmers, pre-existing health conditions).
- Health disclosure prompt: heart condition, pregnancy, recent surgery, etc. — advise "consult your
  doctor first," do not attempt to medically screen anyone in-house.
- Photo/video release (optional checkbox) if the shop wants to film a testimonial.
- Minors: parent/guardian signature line, and a minimum age or adult-supervision rule.
- Signature, printed name, date.

### Changing plan

- Confirm there's a private space for the tester to change (existing restroom vs. a dedicated changing
  area) before offering wet tests publicly; note here which one the showroom will use once decided.
- Towels: shop-provided or bring-your-own — decide and put it on the booking confirmation.

### Bookable slots (April–September)

- One tester (or one party) per slot; slot length to be set once a session is timed in practice (lay out
  the first few slots as, e.g., 30 minutes, and adjust).
- Buffer between slots for sanitizing-log turnaround, not back-to-back.
- Book through whatever the shop already uses for consults (`/book`) — no new booking tool.

### Waitlist (opens February)

- A simple sign-up (name, phone/email, preferred month) opening in February for the April–September
  season; first-come as slots are confirmed.
- Collect interest on the swim-spas page or at the counter — implementation (site form vs. paper list)
  is a separate decision, not made here.
